# JustMark Logo 设计说明

## 设计理念

JustMark的logo采用极简主义设计，体现了应用"简单、专注、高效"的核心价值。

### 设计元素

1. **字母 "J"**
   - 代表 "Just" - 简单直接
   - 流畅的曲线展现书写的自然感
   - 顶部的圆点强调细节与专注

2. **底部笔触**
   - 水平线条象征着书写的动作
   - 尾部的圆点暗示持续创作的韵律
   - 体现Markdown写作的流畅体验

3. **配色方案**
   - 深色背景 (#1a1a1a)：专业、沉稳
   - 白色前景 (#ffffff)：简洁、清晰
   - 高对比度确保在各种场景下的可识别性

## 技术实现

- **格式**: SVG (矢量图)
- **尺寸**: 1024x1024 基准
- **圆角**: 180px (适配现代应用图标风格)
- **导出格式**:
  - PNG (多种尺寸)
  - ICNS (macOS)
  - ICO (Windows)

## 使用的工具

- SVG 手工绘制
- Sharp (Node.js图像处理库)
- iconutil (macOS)
- png-to-ico (Windows图标生成)
